# Larica Burguer

> Sistema de gerenciamento e cardápio digital para a hamburgueria Larica Burguer.

O **Larica Burguer** é uma aplicação web desenvolvida para modernizar o atendimento e a visualização de produtos de uma hamburgueria artesanal. O projeto foi concebido como parte das atividades práticas da disciplina de Programação Web (PNT2), focando em usabilidade, design responsivo e uma experiência fluida para o usuário.

---

## Funcionalidades

- **Cardápio Digital:** Visualização detalhada de hambúrgueres, acompanhamentos, bebidas e combos.
- **Responsividade Total:** Interface adaptada para smartphones, tablets e computadores.
- **Interface Intuitiva:** Layout limpo e focado na conversão visual dos produtos.

## Como Executar o Projeto

Para clonar e executar esta aplicação em sua máquina local, você precisará de um navegador web atualizado e do Git instalado.

### 1. Clonar o repositório
Abra o terminal ou prompt de comando e execute:
```bash
git clone https://github.com/jeffdfreitas/projeto_pnt2_at1.git
```

### 2. Entrar no diretório do projeto
```bash
cd projeto_pnt2_at1
```

### 3. Executar a aplicação
Como o projeto é composto por arquivos estáticos, basta abrir o arquivo principal no seu navegador:
* Dê um duplo clique no arquivo `index.html` na pasta do projeto.
* *Ou*, caso use o VS Code, utilize a extensão **Live Server** para rodar um servidor local em `http://127.0.0.1:5500`.
